# Генерация никнеймов — AtomicInteger и AtomicBoolean

## 📋 Описание задачи

Сгенерировать 100 000 коротких слов (длиной 3–5 символов) из букв `a`, `b`, `c` 
и подсчитать, сколько среди них «красивых» никнеймов. Слово считается «красивым», 
если выполняется **хотя бы одно** из условий:

1. Является **палиндромом** (например, `abba`, `aaa`).
2. Состоит из **одной и той же буквы** (например, `aaa`, `bbb`).
3. Буквы идут **по возрастанию** (например, `aaccc`, `abc`).

Проверка каждого критерия — в **отдельном потоке**. Счётчики для длин 3, 4, 5 — 
в статических полях. Использовать `synchronized` **нельзя** — только `AtomicInteger`.

## 🎯 Цель

Отработать:
- Использование `AtomicInteger` для потокобезопасных счётчиков;
- Использование `AtomicBoolean` с `compareAndSet` для защиты от двойного подсчёта;
- Создание потоков через `new Thread(Runnable)`;
- Ожидание завершения потоков через `join()`;
- Понимание разницы между `synchronized` и атомарными классами.

## 🛠️ Используемые технологии

- Java 17+
- Spring Boot
- `AtomicInteger`, `AtomicBoolean`
- `Thread`, `Runnable`
- Maven
